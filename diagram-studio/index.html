About

Diagram Studio is a free, fully client-side diagramming tool. Create flowcharts, architecture diagrams, network topologies, ERD schemas and sequence diagrams.

Everything runs in your browser. No account, no trial, no limits. Your work is auto-saved locally in your browser.

Host it anywhere static files are served, including GitHub Pages.
